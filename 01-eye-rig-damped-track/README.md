# Rig Character Eyes in Blender — Damped Track Explained

Project files for [this video](https://youtube.com/watch?v=XXXX).

Two eye spheres aimed at a single empty using the Damped Track
constraint, with Track Axis set to Y.

**The concept:** Damped Track takes the shortest rotation to the
target and leaves roll untouched. Track To does not — the video
switches between them so you can see the unwanted roll appear.

**Gotcha covered:** eyes crossing when the target moves close to
the face.
